# 项目进展

2026-11-09：同一 GitHub 仓库主分支同时包含 `windows/` 和 `android/`，优化前的 APK 与源码已保留在 `android-v0.1.0-preview.1`。

两端界面与设计风格保持一致，目前以 PC 为基准。安卓版设置已对齐为模型、外观、常规、提示词四页：可调整尺寸、球色、眼睛色、历史数量与六项提示词，提示词支持单项/全部恢复默认，并在新对话中生效。

边缘陪伴使用 PC 的薄球帽、耳尖与探眼姿态，可二维拖动、吸附最近的左右侧并记住高度；点击只互动，不激活搜索。独立唤起从停靠点飞入，退出后回到原侧原高。局部手势排除解决拖动被系统返回抢走的问题。开始输入不再横飞换侧，其余动效保留。

普通打开通过已授权的无障碍服务先截屏、后打开聊天；系统助理也可提供截图。捕获按具体请求交付，旧请求不能串给新入口。原始截图、拍摄及图库图片只保留在会话内存，模型收到正确来源、完整图片和选区标记；追问复用首轮图片，不重复加入同图。PC 与 Android 均明确仅处理鼠标附近或框选内的对象，其余画面只用于增强理解。

相机在应用内取景，横屏固定 4:3、竖屏 3:4，居中裁切铺满；兔球向上看并担任快门，两侧取消/切镜按钮保持球体直径的 75%。照片保留实际取景范围并按设备姿态转正，不写相册。输入条相机按钮弹出带动效的“拍照 / 上传照片”菜单。

开始对话后隐藏截图、整排功能按钮及输入条图片入口，兔球飞往左上安全带，消息从其下方延伸到输入框上方。Markdown、LaTeX 和来源图标直接沿用 PC 渲染规则；设置暂离保留草稿、选区和滚动。已修复相机遮住照片入场、入场中断留下半透明状态及角色隐藏后仍运行无限动画，并补齐设置切页、高级区与提示词切换动效。

Android 构建、Lint 和五组检查通过；PC 构建及 34 项针对性测试通过。模拟器已实际检查四页设置、快捷方式图标、边缘互动、激活返程、输入不换侧、相机与 160% 尺寸避让；尺寸已恢复 100%。未调用真实付费模型服务。详细结论见 `docs/android-review.md`。

输入、选择器、菜单、气泡和图像外壳已统一圆角层级，新增照片来源菜单包含进入、退出及中断清理。

照片来源菜单已收窄、使用输入外壳同款圆角并左对齐。“常规”页分别说明无障碍和系统助理的用途及独立性，助手入口显示已设置状态。

圈选工具栏已删除重复的拍照按钮，拍照与图库统一从输入条相机菜单进入；开聊后图片入口隐藏并让出输入空间。助手气泡左边缘、用户气泡右边缘分别对齐输入框两侧，气泡沿用输入框的 24dp 圆角。

用户气泡发出后立即清空输入框，等待回复时继续输入的新草稿不会被完成、失败或取消覆盖。请求过程显示 PC 同款兔球信号发射、思考秒数及实际搜索次数，结束后移除进度。

此前已发布双端 0.1.2，发行入口为 [GitHub v0.1.2](https://github.com/emmm1e3m/RabbitBall/releases/tag/v0.1.2)。Windows 提供 x64 ZIP；Android 提供可覆盖预览版的非调试 APK。当时 Windows 161 项测试、Android 构建/Lint/五组设备检查通过，已实测发送清空、两次搜索计数、信号、公式渲染及新草稿保留；测试配置和历史已恢复，模拟器安装了发布 APK。设置页密钥显示已修复为遮挡。

本地 Android 0.1.3：历史改为带图片预览的动画浮层，新记录的预览只保存在私有历史中并随记录删除；四个快捷按钮与发送按钮同为 40dp。长回复修复触摸滚动与视口测量，当前可见气泡始终保留四角圆角。相机横屏4:3、竖屏3:4，已实际验证横竖切换、快门避让及拍摄不入相册。构建、Lint和五组检查通过，原历史/配置与设备状态已恢复，已导出并安装本地签名APK；这些改动已纳入本次 0.1.3 发布。

Android 0.1.3：以系统助理为推荐入口，无障碍作为备用；助理直接显示悬浮窗口，背景快速模糊后呈现截图与控件，日常聊天不再打开 Activity。长回复改为原生同步圆角裁切，消除逐滚动 JavaScript 遮罩的滞后。输入框显示待发图片，空文本退格或叉号可取消附图；历史首条消息显示已保存图片。按钮图标统一颜色和实际尺寸，搜索/历史与拍照/发送中心对齐；普通按钮沿用输入框的半透明白色，发送保留浅粉色。输入随文字增高，最大约为宽度的3/4并适应键盘和横屏，超过后框内滚动。返回优先关闭当前菜单、历史、相机或键盘，再退出会话。构建、Lint、五组设备检查通过，已实测助手相机/选图返回、横竖切换、长文滚动、图片历史和超长输入；签名安装包为 `android/release/RabbitBall-Android-0.1.3.apk`，已随本次双端更新发布。
