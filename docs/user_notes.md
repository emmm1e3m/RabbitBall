# 项目进展

2026-11-08：原桌面版已移至 `windows/`，安卓版工程在 `android/`，Android Studio 已创建并同步工程。

两端界面与设计风格保持一致，目前以 PC 版为设计基准。安卓版按触控和系统交互适配，沿用 PC 的兔球、配色、图标和动效风格，模型与搜索工具对齐 PC 的 DeepSeek 实现。

普通打开使用一次授权的无障碍截图；先取得当前屏幕，再打开聊天界面，避免旧聊天启动快照进入截图。系统数字助理手势由系统提供截图。连接中断时可从界面重新连接，普通打开不弹系统共享确认。可选择边缘陪伴或平时隐藏、激活飞入；设置从桌面图标长按进入。

当前激活界面为略缩完整截图、16dp 高斯模糊与约 14% 变暗的同图背景，进入用 400ms 非线性过渡。悬浮按钮左侧依次为搜索、提取、翻译、拍照，右侧为历史；视觉尺寸和 5dp 间距参考 PC。输入条无提示文案，左侧「＋」调用 Android 系统照片选择器。读取期间问题仍可编辑，取消保留原会话，导入后进入新照片框选。

相机在应用内取景，照片按设备姿态校正为正向像素。取景按原比例居中裁切铺满，回传保留完整照片。兔球飞到底部中央当快门，轻微向上看向取景框，左侧取消、右侧切换前后摄，两侧按钮放大至球体直径的 75%；点击时先播放 PC 的 `>_<` 与爱心再拍摄，拍完飞回。拍照、导入与截图均只在会话内存，不写相册或应用图片缓存；拍照成功也保留已输入的问题。

兔球为 96×108dp，速度按前一版的 75%，拖动和飞行避开输入与聊天内容。默认左半屏朝右、右半屏朝左，输入时飞向另一侧并看向输入框。点击互动按 PC 源码对齐，不绘制底部椭圆阴影。键盘弹出时截图保持原比例向上平移；白色圈选有轨迹粒子与收拢动效，四角可拖动调整。

开始对话后隐藏截图和圈选，多轮气泡直接浮在模糊背景上，长对话可向上滚动回看，气泡入场和列表衔接配套自然弹簧动效。Markdown、LaTeX 与来源图标沿用 PC 渲染器，公式字体本地打包；历史仅保存文字。从设置返回保留当前选区、草稿与滚动位置。

构建、Lint 和五组测试已通过，覆盖相机方向、切镜状态、选图、发送动效及原有截图/富文本行为。模拟器已实际验证前后摄像头裁切铺满、兔球快门拍照返回、系统选图与取消、发送气泡衔接；拍照没有新增相册记录，测试夹具已清理。测试未使用真实付费模型请求，实际使用需填写自己的 API Key。

后续新增界面和交互默认配套入场、退出、状态衔接与中断反馈，自定义动画遵循系统动画关闭设置。
