# 项目进展

2026-11-09：同一 GitHub 仓库主分支同时包含 `windows/` 和 `android/`，优化前的 APK 与源码已保留在 `android-v0.1.0-preview.1`。

两端界面与设计风格保持一致，目前以 PC 为基准。安卓版设置已对齐为模型、外观、常规、提示词四页：可调整尺寸、球色、眼睛色、历史数量与六项提示词，提示词支持单项/全部恢复默认，并在新对话中生效。

边缘陪伴使用 PC 的薄球帽、耳尖与探眼姿态，可二维拖动、吸附最近的左右侧并记住高度；点击只互动，不激活搜索。独立唤起从停靠点飞入，退出后回到原侧原高。局部手势排除解决拖动被系统返回抢走的问题。开始输入不再横飞换侧，其余动效保留。

普通打开通过已授权的无障碍服务先截屏、后打开聊天；系统助理也可提供截图。捕获按具体请求交付，旧请求不能串给新入口。截图、拍摄及图库图片只保留在会话内存，模型收到正确来源、完整图片和选区标记；追问复用首轮图片，不重复加入同图。PC 与 Android 均明确仅处理鼠标附近或框选内的对象，其余画面只用于增强理解。

相机在应用内取景，居中裁切铺满；兔球向上看并担任快门，两侧取消/切镜按钮保持球体直径的 75%。照片按设备姿态转正，回传完整画幅供圈选，不写相册。输入条加号调用系统照片选择器。

开始对话后截图让位给多轮气泡。Markdown、LaTeX 和来源图标直接沿用 PC 渲染规则；设置暂离保留草稿、选区和滚动。已修复相机遮住照片入场、入场中断留下半透明状态及角色隐藏后仍运行无限动画，并补齐设置切页、高级区与提示词切换动效。

Android 构建、Lint 和五组检查通过；PC 构建及 34 项针对性测试通过。模拟器已实际检查四页设置、快捷方式图标、边缘互动、激活返程、输入不换侧、相机与 160% 尺寸避让；尺寸已恢复 100%。未调用真实付费模型服务。详细结论见 `docs/android-review.md`。
