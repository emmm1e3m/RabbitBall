# 兔球 RabbitBall

同一只兔球，分别适配 Windows 与 Android。

- `windows/`：原有桌面版，包含源码、依赖、文档与发行包。开发命令在该目录中执行，见 [Windows 说明](windows/README.md)。
- `android/`：Android Studio 工程，面向 Android 11 及以上设备，见 [Android 说明](android/README.md)。

Android 版以当前屏幕为入口：唤起、圈选、提问。首次启动进入设置，之后打开应用直接开始采集屏幕。模型服务与 Windows 版保持一致。

## 设计约定

Windows 与 Android 两端的 UI、设计风格应保持一致，当前以 PC（Windows）版为设计基准。兔球造型、配色、图标、控件样式、动效与文案风格均沿用 PC 版；安卓版只根据触控、屏幕尺寸和系统交互做必要适配。修改任一端界面时，应同时检查另一端的一致性，避免形成两套独立视觉体系。

动效是新增界面与交互的默认组成部分：同时完成入场、退出、状态衔接与取消/失败反馈，以自然的非线性弹簧和连续运动保持一致；流式更新不反复重播入场，尊重系统减少动态设置。不等待用户逐项提出补动画。

默认兔球的共享静态资产位于 `assets/`。Windows 使用透明图标，Android 桌面图标按用户要求使用黑底，角色本身使用同一默认形态。
