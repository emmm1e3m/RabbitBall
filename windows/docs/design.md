# RabbitBall 设计与实现

更新日期：2026-11-06

RabbitBall 采用 Electron + TypeScript，使用代码分层绘制悬浮果冻兔球。Windows 桌面版将焦点窗口截图、快捷输入、DeepSeek 搜索分析与设置收进同一套界面；浏览器预览用于交互演示，回复和截图为明确标记的示例。

## 1. 主要交互

1. 触发键默认左 Alt，可在通用设置中录制单键或组合键。完整按下不足 500ms 时，松开后使用焦点窗口默认图进入提问；达到 500ms 才进入选区模式并接管鼠标拖选。可跨屏连续框选多张；短按应用图与长按框选独立，长按没有有效选区则不附图。截图期间保持原应用焦点，兔球与聊天暂时避让。
2. 松开触发键 后等截图、裁图完成，按当次鼠标位置计算最终配对布局。激活立即显示可点击输入框、播放光效并请求系统与输入焦点，兔球同时沿曲线飞到框旁；焦点请求失败也保留界面。剪贴板复制在后台继续，不阻塞开框。Alt+Tab 等键盘组合取消截图并保留系统行为；Esc 取消时恢复原聊天，不提交消息。
3. 当前截图以多张缩略图预填，可逐张移除。默认窗口图带空心鼠标标记；选区图保持所选内容。发送后移除本批缩略图，图片保留在原始消息历史中供追问使用。已有会话再次显式截图，可将新的一批附到下一轮。
4. 小框只保留附件、空白输入和发送，不显示占位文案；下面提供搜索与解释、提取文字、翻译。快捷动作直接提交，内置提示词不作为用户气泡显示，自定义输入照常显示。回车或发送展开完整对话，流式生成时发送位置复用为停止按钮。
5. 每条完成的回复提供重新生成与复制图标；重新生成回到所选问题并替换其后的分支，复制取得回复正文。收起回到小框，Esc 或点击外部关闭；关闭后再次打开开始新会话。
6. 激活时按鼠标所在半屏确定位置：左半屏时输入框在左、兔球在右，右半屏反向排列。小框按可用空间在 220–360px 间调整，展开与收起保持本次左右关系。兔球看向输入区域；关闭跟随时平时露出边缘薄球帽，激活飞到输入框旁，关闭后飞回。
7. 激活反馈以激活瞬间的鼠标位置为固定圆心等比扩散，用主题色和白光覆盖焦点窗口，扩散时长 2.1 秒，随后消退。圆形最大半径取鼠标起点到窗口四角的最远距离，窗口矩形仅负责裁切。展开、收起、位置和尺寸变化延续柔和动画。

界面以白色为主，主题色用于文字层级和必要的交互强调。不加入语音按钮、欢迎卡片或重复操作入口。

普通文本、控件、代码与截图提示统一使用本地BC恋爱小行星字体，各处原字号增加2px，公式保留KaTeX字体。空输入时Backspace逐张删除最后图片，长按使用系统重复按键节奏连续删除；有文字时照常删字。

跨屏跟随按兔球实际物理位置切换承载窗口，不随鼠标立即搬窗。飞到出口边缘时按距离和速度渐隐，隐藏期间应用新屏坐标；新坐标绘制并确认后约220ms渐入。位置、速度、路径与尺寸按物理坐标衔接，仍使用单个动画窗口；普通屏内动画不回传位置，仅越界时最多30Hz报告。

关闭跟随后跨屏激活共用视口换算与隐藏握手，原停靠点为真实物理起点。角色从屏外飞入时保持透明，进入目标屏后才推进渐入；输入框不等待角色到位。坐标就绪后再聚焦当前面板，取消由主进程按所属轮次通知，旧面板关闭不影响新入场。

所有换屏都先将原生窗口不透明度设为0，再改变窗口位置；新坐标确认前冻结飞行进度，实际起飞且进入可见区域后才推进渐入。

## 3. 桌面运行

### 透明窗口与启动键

当前使用一个透明窗口覆盖所在显示器的工作区，以 `screen-saver` 级别保持置顶。禁用系统调整大小边框，程序仍可在显示器范围与工作区之间切换。平时不取得键盘焦点，透明区域允许点击穿透；聊天和设置打开时按交互区域调整输入。主进程将全局鼠标位置转成当前窗口坐标，提供给角色跟随与点击判断。

Windows 的触发键、外部点击和全屏检测共用一个隐藏的原生服务，无额外 npm 原生依赖。短按保留默认窗口提问路径；按住达到 500ms 才进入选区并消费左键拖选，阈值前鼠标保留系统行为。Alt+Tab 等键盘组合取消模式后按顺序送回系统。前台窗口权限更高或全屏暂停时保留系统原有输入。

截图助手在启动时编译一次，空闲阻塞等待；独立于键鼠钩子，取消和超时结束阻塞请求，下次按需恢复。框选背景以原始BGRA像素传输和canvas绘制，不做PNG/Base64往返；只在500ms阈值后采集，结束清空并隐藏窗口。截图先隐藏兔球，短按与长按使用独立流程：短按调用 `PrintWindow(PW_RENDERFULLCONTENT)` 截取合适应用；长按调用 `CopyFromScreen` 冻结整个多屏桌面，不读取应用窗口。默认应用优先有效前台，焦点落在桌面、任务栏等外壳时按Z序优先鼠标所在屏的合适应用，再考虑其他屏；没有合适应用不添加默认图片。手动框选不依赖应用是否存在。

应用图与鼠标映射使用 `GetWindowRect` 完整边界及物理像素；模型图可加空心鼠标标记，选区图不附加虚构指针。手动背景覆盖各屏物理边界的并集，每屏复用预加载的隐藏窗口与轻量截图页显示，并从总图裁出该屏背景；物理选区共享，各屏按自身实际内容尺寸投影到DIP，支持负坐标和混合缩放。可跨屏拖成一张选区，也可在不同屏连续选区。显示器拓扑或缩放变化时取消本次截图。主进程另将应用边界转换成 `context.focusBounds`，提供给激活光效。

选区遮罩使用不激活窗口的显示方式并保持鼠标穿透，原生钩子提供左键按下与松开事件，30Hz 鼠标坐标驱动选框。框使用主题细边与白色轮廓，小圆角随选区尺寸收敛；仅压暗选区外，内部保持原图。白色尺寸胶囊自动避开屏幕边缘，确认沿相同框形短暂淡出。顶部简洁状态条显示“按住当前触发键连续截图 · 松开提问”、已选张数和 Esc 提示。快拖矩形可先排队，快照就绪后裁切；触发键松开补齐末次拖选后激活聊天，开框、光效、聚焦与飞行并行进行。

所有截图统一存放在 `CaptureContext.images`，应用图与手动选区不会混入同一次截图会话；长按没有拖选时也不补应用图。默认开启自动复制：每次完成选区排队复制干净裁图，短按确认应用图后排队。复制异步按顺序执行，已确认的截图任务继续复制；取消会跳过尚未开始的任务。复制不阻塞聊天激活，关闭该开关仅停用剪贴板写入，截图仍进入上下文。

聊天激活完成布局后启动兔球的 Bézier 与弹簧移动，并立即显出输入框、发出 `chat:open` 播放鼠标起点的正圆光效，再请求聚焦；这些操作不等待移动结束。到达目标后角色自行释放移动锁。聊天与设置共享 Electron 的显示、窗口聚焦和 webContents 聚焦流程，必要时由 Win32 补助；系统聚焦结果不决定界面是否保留，也不关闭窗口的可聚焦能力。焦点与隐藏请求显式绑定所属 `activationId`，旧飞行、旧回调和旧关闭动作不能影响新聊天或设置。

主进程用唯一的激活状态记录本次 `activationId` 与待渲染呈现、可交互两个阶段，阶段转换不等待角色到位。开始截图只取消焦点操作，保留原界面所属关系；取消截图能恢复原聊天或设置。原生窗口禁用后台节流，保证失焦时飞行仍能完成；截图和全屏暂停由应用状态主动控制。

### 托盘和运行开关

托盘图标使用当前球色与眼睛色。单击打开设置，菜单提供设置、快速提问和退出。

设置按功能分成模型、外观、通用、提示词四个页签。提示词按用途选择并编辑，支持恢复当前项或全部默认值；其他页保留原有配置。页签使用轻微位移和淡入淡出，可通过左右方向键切换；跨页保留同一份草稿，底部统一保存，关闭或取消恢复已保存值。

通用页支持录制触发键：可用单个按键、单独修饰键，或修饰键组合。左右修饰键分别显示，保存后才替换全局触发键；录制期间暂时停用触发，Esc、失焦、切页或关闭退出录制，恢复默认回到左 Alt。启动按钮与截图提示显示当前已保存的按键。

提示词由 `electron/prompts.ts` 统一定义六项：系统指令，搜索、提取、翻译操作要求，附件默认提问，以及合并何时搜索与关键词要求的搜索工具说明。每种功能共用一项：空输入点击快捷按钮时直接使用，有用户问题时附加一次操作要求，不再设置另一段“快捷输入”。用户修改只持久化覆盖项，恢复默认会移除对应覆盖。构建将同一份默认资源提供给浏览器预览。系统指令在新对话首轮固定，追问和重新生成保留原始历史。

默认关闭开机启动，开启全屏暂停和跟随。开机启动调用 Electron 的系统登录项接口；合并原生服务每 500ms 检查全屏状态，仅在变化时通知主进程。全屏暂停通过桥接事件停止动画并关闭提问框，同时中断采集、模型请求和启动键拦截；恢复时继续动画，设置面板保留可用。

Windows 是当前原生目标，支持物理单键、左右修饰键与组合键及全局长按框选。其他平台使用 Electron accelerator，只接受平台可表达的普通键组合，注册失败时保留原配置并报错，不支持全局长按框选；焦点窗口捕获仍返回未接入提示。不能以浏览器预览代替原生验证。

## 4. 角色与调色板

角色保留粗白圆边、等大的胶囊耳、色块眼睛和同心圆弧高光，不加黑色描边。身体、耳朵、五官和高光独立变换，待机、跟随、识屏、思考与打盹共用动画循环。保留轻点和双击动作反馈，不显示这两项操作的原生悬停提示。

关闭鼠标跟随且未激活聊天、设置或截图时，兔球向左右屏幕外收起，保留真实本体的白边与渐变薄球帽；近侧露出少量相连的耳尖，双眼收紧并移入可见部分，两侧停靠镜像一致。此时可拖动调整停靠边与高度，释放或鼠标捕获中断后吸附最近一侧，拖动不会触发轻点或双击。聊天激活时飞入并自然恢复完整耳位，关闭时回到同侧同高度，停靠位置保存在本次页面状态。截图选区打开时隐藏并冻结角色，结束后恢复。

默认尺寸为早期大球的 37.5%。设置中的 100% 对应新的基准：桌面版 SVG 宽 92.25px，浏览器根据视口在 89.25–135px 之间取值；浏览器窄屏打开聊天或设置时缩至最多 51px。尺寸滑块在此基础上调整。页面不再绘制额外的鼠标光点。

鼠标停下后才生成一次随机三次 Bézier 路径，位置弹簧跟随导引点，落点留在球体半径之外；移动鼠标时平滑制动，不逐帧重新抽取随机数。移动路径进度与位置弹簧相对上版统一加快 1.5 倍，跟随原有的 1.5 系数继续保留。非移动动画维持既有的 1.25 倍节奏。

高光可绕圆心轻微转动。球体渐变通过本体逆变换抵消摆动和果冻缩放，明暗方向仅随朝向左右镜像。思考信号为两道粗圆弧加圆点，每次在一定角度范围内随机选择方向，并沿径向移出；图标的对称轴始终穿过球心，保持疏开的发射间隔。

调色板只接收球色与眼睛色两个用户颜色，自动派生耳朵、球体渐变、信号、强调文字、次级文字、边界和柔光。白色界面、白边和白色高光作为中性色保留。颜色与尺寸即时预览，取消恢复已保存值，保存后同步托盘图标。

## 5. 智能体与展示

### 对话与搜索

桌面版在主进程调用 DeepSeek，默认模型为 `deepseek-flash`。界面的低、中、高思考强度分别映射为 API 的 `low`、`high`、`max`；内部推理不传给界面展示。

系统指令要求结论优先、准确简洁，以自然段为主，条目确实便于比较或操作时才使用列表。公式必须使用 LaTeX 数学分隔符。任务由用户文字确定，截图、指针和选区提供对象与范围；没有明确问句时，直接解决用户最可能关心的问题，例如报错的处理办法、术语的必要含义。默认不介绍或逐块解读画面，明确要求提取、翻译或解释时按要求处理。

搜索默认输入为“查找鼠标附近或所选范围内，用户最可能需要的信息，直接给出有用结果。”，围绕具体需求检索。屏幕、附件和网页是待分析数据，不能改变指令或扩大工具权限。

生成请求的 `max_tokens` 为 131072，包含内部推理预算；强制搜索规划首轮为 8192。预算提供长回答空间，默认回复仍保持简洁。

当前只注册 `search_web`，调用官方 `/v1/tools/search`。明确选择搜索时，模型先从截图与指针确定具体查询词，再执行搜索；普通提问按需搜索。提取与翻译不提供搜索工具。最多进行三回合工具调用，整次请求设有超时，取消会中止响应流及后续工具执行。

搜索结果保留真实来源 URL；回答缺少来源链接时补充检索来源。程序不向模型开放任意脚本、系统命令或跨应用操作。

### 会话与缓存前缀

主进程按 `conversationId` 维护当前会话的完整消息轨迹，系统消息在创建会话时固定。用户消息、各批截图、模型正文与推理字段、工具调用和工具结果按原样保留，后续只追加新的用户消息及其生成结果，不改写成摘要或截短历史。渲染层仅提交当前输入与轮次标识，不重建模型历史。

Chat Completions 每次请求都发送这份完整轨迹，保留稳定前缀供服务端缓存复用。每批显式截图只随下一条用户消息插入一次，普通追问通过原始历史使用图片，不重复追加；再次按触发键截图才带入新批次。重新生成按 `turnId` 回退到目标原始用户消息末尾，保留其截图、附件和前缀，移除后续生成后重新作答。

### Markdown 与 LaTeX

普通文字按紧凑段落显示；必要的代码、列表、链接和公式可以渲染。Markdown 禁用原始 HTML，KaTeX 不信任外部 HTML 命令，最终结果统一经过 DOMPurify 清理。链接只允许 HTTP(S)，交由主进程在外部浏览器打开；回复中的图片不自动请求远程资源。

支持 `\(...\)`、`\[...\]`、`$$...$$` 和 `$...$`。未闭合公式保持文本，代码块中的美元符号不当作公式；长代码和公式在消息内滚动，不撑开对话框。

## 6. 数据与边界

- 桌面设置保存在 Electron `userData/settings.json`。API Key 仅在主进程使用，持久化时通过系统安全存储加密，渲染进程只取得是否已配置的标志。
- 设置先校验再保存，文件通过临时文件替换；系统安全存储不可用时不写入明文密钥。
- 截图与完整当前会话保留在主进程内存。多张截图可分别移除，发送时主进程按当前上下文的 `imageIds` 校验实际选中项；提交后保留在原始历史中，输入框不再挂载本批图片。只有实际提交消息后才调用模型；截图之外，每次最多另添一个图片或文本文件附件。
- 同时处理一个模型请求；新请求或取消会终止旧请求。上下文 ID 在主进程校验，过期上下文不会被静默替换。
- 浏览器预览使用示例截图和模拟回复；非敏感配置可保存在 localStorage，密钥只保留当前会话，浏览器演示不发送真实 DeepSeek 请求。

当前不接入语音 UI 或云端 ASR。系统听写与离线方案见[语音转文字调研](speech-research.md)：Win+H 需要联网；当前 Windows 11 Voice Access 支持下载中文语言文件后离线听写。后续若需要应用内离线中文，可另行验证 sherpa-onnx。
