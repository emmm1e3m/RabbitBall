# 兔球 · Android

Android Studio 原生 Kotlin 工程，Android 11+，compile SDK 36.1，target SDK 36。使用 Android Studio 自带 JDK 21 和 Gradle 9.3.1。

UI 与设计风格遵循根目录的[设计约定](../README.md#设计约定)，当前以 PC 版为准，复用其兔球造型、配色、图标和动效风格。

Android 桌面图标使用黑底与默认兔球前景；Windows 图标和共享角色 PNG 保持透明背景。Pixel 桌面推荐位置显示的粉色外环由系统添加，不包含在兔球图标资产中。

## 使用

首次启动进入设置。填写 DeepSeek API Key；模型与思考强度选择器沿用 PC 风格，默认模型为 DeepSeek Flash，工具调用上限为 3 轮。模型也可选择 DeepSeek V4 Pro。

普通打开使用「常规」页中「即开即选」对应的无障碍服务，一次授权后直接截图。也可以将兔球设为系统数字助理，通过助理手势或按键唤起，此时由系统提供截图。服务仅在主动唤起时获取屏幕，不读取界面节点、不执行点击。未配置或连接中断时，轻点空态中央图标即可打开授权设置，返回后自动重试。普通打开不会自动弹出系统共享确认。

「屏幕边缘陪伴」开启时，兔球沿用 PC 的薄球帽、耳尖与探眼姿态，可拖出并在松手后吸附最近的左右边缘，记住停靠高度；点击只播放表情与爱心，不触发搜索。独立唤起搜索时从实际停靠点飞入，退出后飞回。关闭陪伴时平时不显示，激活后从屏幕外飞入。系统数字助理和快捷设置磁贴也可作为入口。长按桌面图标可进入设置。

激活界面保留略微缩小的完整截图，同画面以 16dp 高斯模糊和约 14% 变暗作为背景，进入时用 400ms 非线性过渡。独立悬浮按钮左侧依次为搜索、提取、翻译，右侧为历史；沿用 PC 的图标和按钮样式，可见间隔为 5dp。输入条左侧为相机图标，点击弹出“拍照 / 上传照片”浮动菜单；右侧为发送，无提示文案。

圈画时粒子跟随轨迹，抬手后收拢成圆角范围；四角可拖动调整，框内可移动，在已有选区外起笔即可重新选择。发送的是带区域标记的完整图片：选区按全图归一化，模型收到像素坐标说明和绘于副本上的粉色圆角框，原图不变。截图、相机和图库来源分别说明；同一会话的追问保留首轮图片，不重复加入同图。开始对话后隐藏截图、圈选、整排功能按钮和输入条图片入口，兔球飞往左上安全区域；气泡从其下方延伸至输入框上方，悬浮在模糊背景上，可滚动回看。气泡到达与列表衔接使用弹簧动效。使用系统返回手势回到原应用，不额外显示返回按钮。

输入条的相机菜单可选择界面内拍照或 Android 系统照片选择器。读取照片时保留可编辑的问题，并显示读取状态；取消选择保留原会话，确认照片后作为新的视觉上下文进入框选。选择拍照后打开界面内取景器：兔球飞到底部中央当快门，轻微向上看向取景框；左侧取消，右侧切换前后摄，两侧按钮边长为兔球球体直径的 75%。点击兔球先显示 PC 的 `>_<` 表情与爱心，再拍摄，拍完飞回。取景按原比例居中裁切铺满，回传照片仍保留全图；相机根据设备姿态把照片像素校正为正向。

兔球支持拖动和点击爱心互动，不绘制底部椭圆阴影。位于左半屏时朝右看，右半屏时朝左看；输入时保持原侧并看向输入框。转向沿用 PC 的脸部、耳朵、高光和明暗过渡，飞行与拖动均避让对话面板。键盘弹出时，截图保持原来的缩放比例向上平移，允许上方内容超出屏幕。从设置返回保留选区和草稿；发出用户气泡后立即清空输入，等待期间可继续写新草稿，完成、失败或取消均不覆盖新输入。回答中的网页来源可直接点击。

请求进行时沿用 PC 的双波纹信号发射，显示本次经过的思考秒数，以及实际搜索调用累计次数。结束或取消后移除进度；后台停止绘制和计时刷新，回到同一请求时继续显示经过时间，历史对话不启动进度。

截图、拍摄与导入照片只保存在会话内存，不写入相册、应用图片缓存或剪贴板。相机取消保留原会话与草稿，拍照和导入成功也保留已输入问题；对话历史仅保存文字，保留数量默认 10 条，可在常规页调整。API Key 通过 AndroidKeyStore 加密。受系统保护的页面无法截图。

设置与 PC 对齐为“模型、外观、常规、提示词”四页。外观支持 60%–160% 的尺寸、球色和眼睛色；提示词提供六项用途，支持单项与全部恢复默认，保存后在新对话中生效。常规页保留 Android 授权入口与边缘陪伴，并可调整历史保留条数。

## 开发

Android Studio 打开本目录，同步后运行 `app`。命令行构建：

```powershell
$env:JAVA_HOME = 'C:\Program Files\Android\Android Studio\jbr'
.\gradlew.bat :app:assembleDebug
```

开发 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。调试版本允许本地 HTTP 模拟接口，正式构建只允许 HTTPS。

对话内容使用单个本地 WebView，构建时从同仓库 `windows/prototype/rich-text.js` 同步 PC 渲染规则；Android 工程需保留同级 `windows/` 源码。Markdown、KaTeX 与公式字体均随 APK 打包，不请求网络资源；来源链接沿用 PC 图标，点击后交给系统浏览器。支持行内 `$…$`、`\(…\)` 和独立 `$$…$$`、`\[…\]` 公式。

模型调用沿用桌面版的 DeepSeek Chat Completions、思考参数、`search_web` 工具及搜索接口。测试运行器连接本地模拟服务，不使用真实密钥、不产生付费请求：

```powershell
.\gradlew.bat :app:assembleDebugAndroidTest
adb install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell am instrument -w com.rabbitball.app.test/com.rabbitball.app.AiSmokeInstrumentation
```

当前构建、Lint（0 errors）和五组 instrumentation 已通过。模拟器已验证照片来源菜单、相机进入与取消、系统照片选择器，以及开聊后隐藏工具和图片入口、兔球顶部避让及气泡对齐。

圆角按组件层级统一：小控件 10dp，设置输入与选择器 16dp，输入外壳、对话气泡、照片来源菜单、图片与取景区域 24dp；圆形控件保持全圆。助手气泡左边缘、用户气泡右边缘分别对齐输入外壳两侧。

“常规”页明确区分两个独立入口：无障碍用于直接打开时截图与边缘陪伴；系统助理设置用于助理手势或按键唤起，截图由系统提供。按使用方式选择即可，无需两项同时开启。
